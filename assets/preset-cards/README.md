# Biblioteca de cartas

Use estas pastas para cartas individuais da biblioteca.

- `classes`
- `racas`
- `divindades`
- `reacoes-heroicas`
- `herois`

Em cada pasta, coloque uma imagem de verso chamada `Verso.png` e as frentes das cartas com qualquer nome.

Depois rode:

```bash
npm run build:preset-decks
npm run build
```

O comando `build:preset-decks` atualiza a biblioteca de pilhas e a biblioteca de cartas.
